# Опровергни свой результат (CoVe)

Модель тянет к убедительности, а не к честности. Этот скилл атакует собственный
вывод до того, как он попадёт к человеку. Главное правило — отвечать на проверочные
вопросы **с чистого листа**, не «защищая» свой черновик.

## Когда запускать
**Да:** расчёт, прогноз, рекомендация, юнит-экономика, коммерческое предложение, анализ данных.
**Нет:** отправить сообщение, обновить ячейку, технические задачи без числовых выводов.

## Процесс — 5 вопросов
Прогони по готовому выводу.

1. **Допущения.** Какие данные взяты неподтверждённо? Что принято за факт без источника? Какие цифры оценочные, а не реальные?
2. **Три причины провала.** Почему результат может не сработать в реальности? Минимум три — конкретные для этого расчёта.
3. **Альтернативные объяснения.** Цифра X означает «работает» — или «сложение оптимистичных допущений»? Что ещё могло дать такой результат?
4. **Что не проверено.** Какие источники остались за бортом? Какие данные нужны, но не получены?
5. **Имитация vs результат.** Где подгонка под убедительность? Смешаны ли разные сущности в одной колонке (деньги + PR-эквивалент, реальное + условное)? Выглядит ли итог лучше, чем есть?

## Формат вывода
```
🔍 ПРОВЕРКА — [название расчёта]
1. ДОПУЩЕНИЯ: [...]
2. ТРИ ПРИЧИНЫ ПРОВАЛА: [...]
3. АЛЬТЕРНАТИВНЫЕ ОБЪЯСНЕНИЯ: [...]
4. НЕ ПРОВЕРЕНО: [...]
5. ИМИТАЦИЯ VS РЕЗУЛЬТАТ: [...]
⚠️ УЯЗВИМОСТИ: [1-2 главных риска]
✅ МОЖНО ПОКАЗАТЬ / 🔴 ТРЕБУЕТ ПРАВКИ: [вердикт]
```

## После прохождения
Если вердикт «МОЖНО ПОКАЗАТЬ» — создай маркер (его ждёт хук pre-show-calculation):
```bash
touch /tmp/falsification-done
```
Если «ТРЕБУЕТ ПРАВКИ» — сначала исправить, потом снова пройти проверку.

## Пример
**Вывод до проверки:** «+22 млн доп.доход, ROMI +52% ✅»
**После 5 вопросов:**
- Допущения: 30% реализации тиража — нет данных.
- Причины провала: партнёр не согласует / логистика убивает экономику / продукт продаётся и без промо.
- Имитация: 15 млн (касса) + 7 млн (PR-эквивалент) = 22 млн в одной строке «доход» — это разные сущности.
**Правка:** разделить на две строки — реальные деньги отдельно, бренд-актив отдельно.
