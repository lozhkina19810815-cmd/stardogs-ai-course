# Строгое заземление

Факт берётся из источника, а не из памяти модели. Память — только для общих знаний
и языка. Любая конкретика (цифра, дата, имя, ставка, статус, состав) — из открытого
файла/коннектора, с указанием откуда.

## Правила
1. **Отвечай только по открытым источникам** — файлы проекта (Read), коннекторы (Gmail/Drive/Sheets/CRM), веб-поиск. Не «по памяти».
2. **На каждый факт — источник.** В скобках: «по файлу `прайс-май.xlsx`, строка 12» или «по Таблице …».
3. **Нет данных — пиши «в источниках нет»** и проси нужный файл/доступ. Не заполняй пробел догадкой.
4. **Сначала открой, потом утверждай.** Если источник по теме не открыт в этой сессии — открой его перед ответом.
5. **Проверь свежесть.** Если документ старше нескольких месяцев — пометь «возможно устарело», предложи перепроверить.

## Что сказать агенту (пресет)
```
Отвечай только по загруженным файлам проекта и коннекторам. На каждую цифру/дату/имя
укажи, из какого файла и строки она взята. Если данных нет — ответь «в источниках нет»,
не придумывай. Если файл по теме не открыт — сначала открой его.
```

## Самопроверка перед отправкой
- [ ] Каждый факт сопровождён источником?
- [ ] Оценки и допущения помечены как оценки, а не поданы как факты?
- [ ] Нет утверждений «по памяти» без открытого файла?

## Граница
Заземление снижает галлюцинации, но не гарантирует ноль ошибок: мусор в файлах
(устаревший прайс) или открытие не того файла → «источник есть», а ответ неверный.
За актуальность файлов отвечает их владелец.
