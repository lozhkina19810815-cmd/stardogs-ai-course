# Стартовый комплект: защита от галлюцинаций

Готовые файлы для вашего агента на Cowork (Claude Code) — спутник [Урока 3 Блока 3 «Верификация»](../lesson16.html). Скачайте, скопируйте к себе, подключите. Это и есть ШАГ 3 и ШАГ 4 из урока — не «скажи агенту настрой», а готовые рабочие файлы.

## Что внутри (папка `templates/`)

| Файл | Что делает |
|---|---|
| `hooks/pre-show-calculation.sh` | **Хук CoVe-гейт.** Не даёт записать/показать расчёт (отчёт, прогноз, .xlsx/.docx) без проверки `/falsify`. |
| `hooks/source-check.sh` | **Хук заземления.** Не даёт утверждать факт по вашей теме (цены, меню…), если агент не открыл источник в этой сессии. *(Упрощённая версия — добавьте свои темы.)* |
| `skills/falsify/SKILL.md` | **Скилл CoVe** — проверка расчёта 5 вопросами с «чистого листа». |
| `skills/grounding/SKILL.md` | **Скилл заземления** — отвечать только по источникам, с указанием откуда. |
| `settings.example.json` | Пример, как подключить хуки в `settings.json`. |

## Установка (5 минут)

> Нужен `jq` (обычно уже есть; проверка: `jq --version`).

1. **Скопируйте файлы к себе** (из папки `templates/` в вашу `.claude/`):
   ```bash
   cp templates/hooks/*.sh    ~/ВАШ-ПРОЕКТ/.claude/hooks/
   cp -r templates/skills/*   ~/ВАШ-ПРОЕКТ/.claude/skills/
   ```
2. **Сделайте хуки исполняемыми:**
   ```bash
   chmod +x ~/ВАШ-ПРОЕКТ/.claude/hooks/pre-show-calculation.sh
   chmod +x ~/ВАШ-ПРОЕКТ/.claude/hooks/source-check.sh
   ```
3. **Подключите хуки** — откройте `settings.example.json`, скопируйте блок `hooks` в свой `.claude/settings.json` (если файл уже есть — добавьте записи внутрь, не перезатирая).
4. **Перезапустите сессию** агента, чтобы он подхватил настройки.

Или просто скажите агенту: «Возьми файлы из этого комплекта, разложи по `.claude/hooks/` и `.claude/skills/`, сделай хуки исполняемыми и пропиши их в settings.json».

## Проверить, что работает

- Попросите агента записать любой расчёт в `.xlsx` → хук должен **заблокировать** с просьбой пройти `/falsify`.
- Пройдите `/falsify`, затем `touch /tmp/falsification-done` → повторите → пройдёт.

## Под себя

- **`source-check.sh`** — в массиве `RULES` задайте свои темы и источники (по образцу: «цены → файл с прайсом»).
- **`pre-show-calculation.sh`** — при желании поправьте слова-признаки расчётного файла под свою зону.

## Важно

Это **упрощённый** комплект для старта. Хуки ловят факт действия — это сильнее, чем правило в CLAUDE.md (его агент забывает). Но они не заменяют человека: юридические формулировки, финансы с последствиями, сложную аналитику проверяет эксперт (см. урок, раздел «Где нужен человек»).
