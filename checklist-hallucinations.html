Спутник Урока 3 Блока 3 · Definition of Done

Чек-лист: защита от галлюцинаций ИИ-агента

Сначала настрой один раз, потом проверяй каждый результат
Чек-лист из двух частей. Часть A — настроить агента один раз (тогда он защищает сам). Часть B — пройти перед тем как доверять конкретному результату. Всё — для агента на Cowork (Claude Code).
Часть A · Настроить один раз

⚙ Что конкретно сделать (4 шага)

Скажи эти команды своему агенту — он сам всё настроит. Главное: одного правила в CLAUDE.md мало (агент забывает) — рычаг это хук. Готовые файлы: скачать комплект (.zip) · инструкция.
  1. Заземли на свои файлы. Положи рабочие документы (прайс, регламент, выгрузки) в папку проекта агента.
    «Отвечай по данным только из файлов проекта или коннекторов. На каждую цифру указывай, из какого файла и строки она взята. Нет данных — пиши "в файлах нет", не придумывай».
  2. Дай 4 правила в CLAUDE.md.
    «Допиши в CLAUDE.md 4 правила: (1) факт — только из файла/коннектора, с источником; (2) после расчёта — CoVe с проверкой «с чистого листа»; (3) при неопределённости — «не знаю» вместо догадки; (4) "готово" ставит человек, не ты».
  3. Поставь хук-проверку. ← рычаг
    «Поставь хук: перед утверждением с данными проверяй, открыл ли я источник в этой сессии (Read/коннектор) — если нет, блокируй. И хук, который не даёт показать расчёт без шага CoVe».
  4. Сохрани приёмы как скиллы.
    «Сохрани два промпта как команды: (1) CoVe-проверка, (2) строгое заземление — чтобы не печатать каждый раз».
Правило: настроил один раз → агент применяет сам. Текст без хука забывается.
Часть B · Проверять каждый результат

1. Заземление сработало

Перед тем как доверять любому факту из ответа агента.
  • Нужные файлы лежат в проекте агента (или подключён коннектор к живой системе) и они актуальны.
  • Агент реально открыл источник в этой сессии (Read / коннектор), а не ответил «по памяти».
  • На каждый важный факт (цифра, дата, имя, ставка, KPI) агент указал: «источник — такой-то файл, строка».
  • Если источник не указан — факт считается недостоверным и наружу не идёт.
Правило: факт без понятного источника = галлюцинация по умолчанию.

2. CoVe — для важных решений

Включаем для документов и расчётов с заметным влиянием (деньги, клиенты, стратегия, то что уходит наружу). На болтовню и черновики — не тратим.
  • Попросили: «Разбей ответ на 3–7 ключевых утверждений».
  • На каждое утверждение сформулирован проверочный вопрос «как именно?» / «откуда это следует?».
  • Агент ответил на вопросы с чистого листа — в новом запросе, без доступа к черновику.
  • Получено сравнение: «что в черновике / что при проверке / где расходится».
  • Все расхождения исправлены либо помечены как «оценка / гипотеза».
Правило: без шага «с чистого листа» CoVe не считается выполненным.

3. Политика «не знаю» вместо уверенного вранья

Поощряем отказ от ответа, а не умное угадывание.
  • При неопределённости агент пишет «не знаю» / «н/д» и запрашивает данные.
  • Если в данных дыры — даёт диапазон с пометкой «оценка», а не одну точную цифру.
  • Прогнозы без истории помечаются «недостаточно данных», а не «скорее всего X».
  • Первые случаи честного «не знаю» — явно поощряются.
Правило: догадка, оформленная как факт, — это баг процесса, а не помощь.

4. Приёмщик-человек

Агент никогда не ставит точку в задаче сам. Приёмщик — не обязательно руководитель: владелец процесса или ревьюер.
  • Агент не ставит «готово / completed» без явного ОК человека.
  • Для каждой задачи понятен приёмщик (кто говорит «принято»).
  • Документы, письма, сообщения перед отправкой смотрит человек-приёмщик.
  • Фразы «вроде готово», «должно работать», «по идее ок» без ОК = задача не готова.
Правило: «Готово» — это действие человека, а не формулировка агента.

5. Быстрый самоконтроль перед отправкой наружу

Перед тем как отправить результат клиенту / партнёру / в чат — три вопроса.
  • Я могу показать источники для всех ключевых фактов и цифр?
  • Все оценки и допущения помечены как оценки, а не поданы как факты?
  • Я готов(а) лично подписаться под этим текстом / расчётом?
Любой ответ «нет» → вернуться на шаги 1–3 (заземление, CoVe, «не знаю») и доработать.
Помни границы: базового набора (части A+B) хватает для FAQ, регламентов, операционных расчётов. Юр. формулировки (168-ФЗ), финансы с последствиями, сложная аналитика — только с сильным человеком, агент там лишь помощник.
