Архитектура агента

Шпаргалка: из чего состоит агент, как элементы связаны, где CLAUDE.md

CLAUDE.md — это точка входа, но не вся система. Агент становится надёжным только когда все элементы работают вместе: правила говорят что делать, guards — что не делать, хуки — блокируют автоматически, handoff — передаёт смену, память — накапливает опыт.

CLAUDE.md — это должностная инструкция.
Остальная архитектура — это система, которая заставляет её работать.

Два типа памяти

Краткосрочная

Передаёт контекст между сессиями. Без неё агент каждый раз начинает с нуля.

Handoff Записка для следующей сессии: что сделано, что дальше, какие решения приняты Аналог: передача смены между сменами
Урок 2
STATE Полная картина всех проектов и статусов. Агент читает при каждом старте Аналог: дашборд проектов
Урок 2
Долгосрочная

Живёт вечно, растёт с каждой сессией. Каждая ошибка → правило, каждый приём → навык.

CLAUDE.md Главные правила: кто вы, как работать, что нельзя. Точка входа во всю систему Аналог: должностная инструкция сотрудника
Урок 1
Guards Запреты и правила «не делать». Каждая ошибка превращается в защиту Аналог: техника безопасности
Урок 3
Память (memory/) Проекты, решения, уроки, контакты, исследования Аналог: корпоративная база знаний
Урок 4
Навыки (skills/) Готовые сценарии для повторяющихся задач: отчёт, рассылка, проверка Аналог: пошаговые регламенты
Урок 4
Правила (rules/) Детальные инструкции по темам: таблицы, отправка, проверки Аналог: справочник процедур
Урок 4

Механизмы контроля

Хуки (hooks) Автоматические проверки, которые агент не может обойти. Срабатывают до или после действия Аналог: сигнализация, которая звонит сама
Урок 5
Задачник Трекер задач с приоритетами и статусами. Внешняя «рабочая память» проектов Аналог: доска задач (Trello, Jira)
Урок 8

Как элементы связаны

СитуацияКакие элементы работают
Агент стартуетЧитает CLAUDE.md → загружает STATE → проверяет handoff
Получает задачуИщет подходящий skill или правило → выполняет → проверяет guards
ОшибаетсяОшибка записывается → превращается в guard → hook блокирует повтор
Отправляет результатHook проверяет перед отправкой → guard напоминает про запреты
Завершает сессиюПишет handoff → обновляет STATE → сохраняет в память
Цикл роста: ошибка → guard → hook → навык.
Каждая сессия делает агента сильнее.
